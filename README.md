# CT - Consciousness Tracer 🧠

一个基于 RAG 和个人意识事件追踪的系统，用于自我反思与决策优化。

## 功能

- 意识事件记录（情绪/念头/行动）
- 向量化存储与语义检索
- 自动标签与洞察生成
- 周报生成

## 技术栈

- Python
- Chroma（向量数据库）
- Sentence Transformers（嵌入模型）
- FastAPI（后端接口）

## 运行

\`\`\`bash
pip install -r requirements.txt
python app.py
\`\`\`
